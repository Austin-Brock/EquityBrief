EquityBrief: Architecture

Next.js app with two entry points: the existing ticker brief page and a new agentic chat page that reuses the same pipeline through tool calls. The agent loop is hand-written on the OpenAI SDK, with no agent framework.

Example: “Tell me what I should know about Apple for my 10am meeting”

  1. Chat page POSTs the conversation to /api/chat; the route opens a stream and runs lib/agent.ts.
  2. Model calls resolve_company("Apple") → Apple Inc., AAPL, CIK 320193.
  3. Model calls get_stock_quote("AAPL") and summarize_10k("AAPL") in parallel. The 10-K summary takes ~10–15s on first run, then comes from the cache.
  4. Each tool emits tool_start (status line) then tool_result; the browser renders results as the existing QuoteCard and BriefView, so the output matches the brief page.
  5. With no more tool calls, the loop emits a text event: a short meeting-prep wrap-up: 3–5 talking points and likely client questions, citing 10-K Items from the brief.
  6. Follow-up (“what did they say about tariffs?”) → search_filing("AAPL", "tariffs") → answer grounded in the returned paragraphs.
